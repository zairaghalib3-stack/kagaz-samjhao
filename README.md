# Kagaz Samjhao

Upload a photo of any Pakistani official document (utility bill, challan, legal notice, bank letter) and get a plain-language explanation in Roman Urdu, Urdu or English.

It tells you what the document is, how much is owed and by when, anything suspicious, and 3 next steps.

![Demo](screenshot.png)

## Built with
HTML, JavaScript and the Gemini API. Runs entirely in the browser.

## How to use
Open index.html, paste a free API key from https://aistudio.google.com, upload a document photo and press the button.
